# Smart Folder Watcher

Небольшой фоновый сортировщик, который наблюдает за папкой и перемещает новые файлы в нужные каталоги по YAML-правилам. Подходит для автоматизации сортировки папки «Загрузки».

## Возможности

- Реальное время на базе `watchdog` и паттерна Observer.
- Условия по расширению, минимальному и максимальному размеру, фрагментам имени.
- Поиск ключевых слов в PDF и фильтрация изображений по EXIF-производителю или модели камеры.
- Поддержка `~` и переменных окружения в путях.
- Ожидание окончания записи файла перед перемещением.
- Защита от перезаписи: при совпадении имени добавляется числовой суффикс.
- Правила проверяются по порядку, применяется первое совпавшее.
- Режим `--dry-run` для проверки настроек без перемещения файлов.
- При запуске сортирует файлы, уже находящиеся в наблюдаемой папке.

## Требования

Python 3.10 или новее.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Настройка

Измените `config.yaml`. `watch_dir` задаёт наблюдаемую папку, `recursive` включает обход подпапок. Относительные пути назначения разрешаются относительно файла конфигурации, а `~` и переменные окружения раскрываются.

Пример правила:

```yaml
rules:
  - name: large-pdfs
    extensions: [.pdf]
    min_size: 1048576
    destination: ~/Sorted/Large PDFs

  - name: camera-photos
    extensions: [.jpg, .jpeg]
    exif_camera: [canon]
    destination: ~/Sorted/Camera photos

  - name: invoices
    extensions: [.pdf]
    pdf_keywords: [invoice, payment]
    destination: ~/Sorted/Invoices
```

В одном правиле можно сочетать несколько условий: они должны совпасть все. Поддерживаемые поля: `extensions`, `min_size`, `max_size`, `filename_contains`, `pdf_keywords`, `exif_camera`, `destination` и необязательное `name`. Размеры задаются в байтах. Расширения сравниваются без учёта регистра. PDF-правила ищут текстовый слой документа; сканированные изображения без OCR не распознаются. EXIF-условия ищут указанные фрагменты в объединённой строке производителя и модели камеры. Для этих проверок установите все зависимости из `requirements.txt`.

## Запуск

```bash
python smart_folder_watcher.py --config config.yaml
```

Проверить правила и предполагаемые перемещения, не меняя файлы:

```bash
python smart_folder_watcher.py --config config.yaml --dry-run
```

Остановить демон можно сочетанием `Ctrl+C`. Для автозапуска поместите команду запуска в systemd, Планировщик заданий Windows или другой менеджер служб.

## Тесты

```bash
python -m unittest discover -s tests -v
```

## Примечания

- Папка наблюдения должна существовать до запуска.
- Сортировщик работает только с файлами верхнего уровня по умолчанию. При `recursive: true` наблюдаются подпапки.
- Используйте назначения вне наблюдаемой папки, особенно при включённом рекурсивном режиме.
- Для файлов, совпавших с несколькими правилами, используется первое правило в конфиге.
